# frontguard

## 0.2.0

### Minor Changes

- [#8](https://github.com/juliocarneiro/frontguard/pull/8) [`43f04d4`](https://github.com/juliocarneiro/frontguard/commit/43f04d4f698366957b683364fc003e1622c29cd7) Thanks [@juliocarneiro](https://github.com/juliocarneiro)! - 8 new rules, based on recent frontend CVEs and incidents (31 in total):
  
  - `FG-XSS-010` `no-open-redirect`: navigation to values from `location.search`/`hash`, `URLSearchParams`, `useSearchParams`, `document.referrer` (open redirect and `javascript:` XSS), with intra-file taint tracking
  - `FG-XSS-011` `no-dangerous-attribute`: dynamic `on*` handlers and `srcdoc`, URL attributes fed from the address
  - `FG-XSS-012` `no-prototype-pollution`: unguarded recursive merge/extend helpers and writes through `__proto__` (the bug class behind React2Shell, CVE-2025-55182, and recent DOMPurify bypasses)
  - `FG-SEC-007` `no-secret-in-public-env`: server secrets behind `NEXT_PUBLIC_`, `VITE_`, `REACT_APP_`, `PUBLIC_`... prefixes
  - `FG-AUTH-004` `no-insecure-random`: `Math.random()` for tokens, nonces, OAuth state, PKCE verifiers
  - `FG-AUTH-005` `no-insecure-cookie`: auth cookies written from JavaScript
  - `FG-CFG-005` `require-message-origin-check`: `message` listeners that never check `event.origin`
  - `FG-CFG-006` `no-exposed-dev-server`: dev server host/CORS/fs protections disabled (Vite CVE-2025-30208, CVE-2025-31125, CVE-2025-24010)

## 0.1.0

### Minor Changes

- [#1](https://github.com/juliocarneiro/frontguard/pull/1) [`8ca5fa8`](https://github.com/juliocarneiro/frontguard/commit/8ca5fa8fc2c7843438d84a68a4cb5ebc34f7a82e) Thanks [@juliocarneiro](https://github.com/juliocarneiro)! - First public release.
  
  - Single-pass, ESLint-style rule engine with a public `defineRule()` API for custom rules.
  - Vue, Svelte, Astro and HTML `<script>` blocks are analyzed with exact positions; new rules for Svelte `{@html}`, `insertAdjacentHTML`/`setHTMLUnsafe`, and `postMessage(…, '*')`.
  - Dependency audit reads npm, pnpm, yarn (v1 and berry) and bun lockfiles, including transitive packages, with real severities, CVE ids and fixed versions from OSV.dev.
  - SARIF output ready for GitHub code scanning (relative paths, fingerprints, `security-severity`).
  - Secrets are masked in every report; browser-safe keys are no longer reported.
  - Validated configuration (`frontguard.config.ts` or `.frontguardrc.json`), `warn` rule level and inline suppression comments.
  - `frontguard init` / `npm create frontguard` set up install, config, script and a CI workflow.
  - Requires Node.js 22.18+.

Release notes are generated by [Changesets](https://github.com/changesets/changesets) from the
files in `.changeset/`.
